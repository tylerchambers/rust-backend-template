## Issues found and corrected

1. Shared old/current Cargo targets could reuse same-named path-package artifacts, invalidating compatibility evidence. Separate targets fixed it; live upgrade passes.
2. Fresh PostgreSQL startup was racy: default socket `pg_isready` succeeded against the temporary bootstrap server while TCP refused. `postgres-readiness-repro.log` captures this directly. All disposable PostgreSQL readiness probes now explicitly use `-h 127.0.0.1`; the complete fresh-environment gate passes.
3. The architecture test initially omitted domain-to-HTTP-framework edges. A deliberate Axum dependency mutation failed the added regression, then the forbidden-edge guard was implemented and the architecture gate passed.
4. A newly added unknown redirect-field HTTP test initially expected 400. The actual Axum JSON-data rejection contract is 422 with stable `invalid_input`; the assertion was corrected to that established rejection contract, not relaxed to accept the request.
