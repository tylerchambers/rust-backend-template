## River jobs
Adopt official River Rust integration with PostgreSQL and SQLx; validate versions and APIs in spike. Use River-owned schema/migrations. Separate worker binary and queue configuration. Typed job payloads with versioned serialization. Enqueue invitation emails in the same business transaction as invitation creation; commit or rollback together. Use retries with bounded exponential backoff, idempotency, concurrency controls, scheduled execution, graceful shutdown and failed-job visibility. Do not build custom leasing/queue machinery. External publication to multiple independent consumers may still require outbox.
## Redis
Optional Redis for distributed rate limiting, tenant-scoped caching and short-lived coordination. Define narrow cache and limiter ports. PostgreSQL authoritative for users, sessions, memberships, jobs. Define operation-specific failure policy: sensitive auth limits should fail closed or use a safe local fallback; noncritical cache failures fall back to source of truth. Namespace cache keys by environment and tenant; TTL and invalidation contract documented.
## Observability
tracing/OpenTelemetry for HTTP, SQL and River jobs. Correlation/request IDs and trace context. JSON logs with secret/token redaction. Metrics for auth failures, tenant denial, queue lag, retries, dead jobs, DB pool pressure, Redis errors and latency. Health/readiness and graceful shutdown.
## Agent protocol
Tickets have stable IDs, dependencies, acceptance criteria and PR evidence. Agents should claim disjoint work, avoid concurrent migration edits, use branch-per-ticket, run just check, add tests and report ADR deviations. Parallelizable initial work: ARC-03 after ARC-01; DB-01 after ARC-01; test harness after DB-01. Integration order follows dependency graph, not arbitrary phases.
## Release gate
Fresh checkout setup, DB migration, seeded tenants, WebAuthn login, revocable session, organization membership, RLS denial, invitation email through River, OpenAPI generation, TypeScript client build, complete negative-security suite, OCI API/worker startup.
