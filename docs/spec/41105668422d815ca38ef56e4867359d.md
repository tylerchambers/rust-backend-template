## Authentication
Passkey-first WebAuthn. Use a maintained vetted Rust WebAuthn library. Verify challenge, RP ID, origin, credential association, user verification policy and replay. Credential creation requires authenticated enrollment or a deliberately constrained initial-registration/recovery ceremony. Treat synchronized passkeys as multi-device credentials.
## Server sessions
Issue \>=256-bit CSPRNG opaque session token in __Host- prefixed Secure HttpOnly Path=/ cookie with deliberate SameSite policy. Persist hash/HMAC of token in PostgreSQL, never plaintext. Idle and absolute expiry; rotation on login/privilege change; revoke one/all sessions; audit session lifecycle. CSRF protection for state-changing cookie-authenticated requests; validate Origin/Referer as appropriate. Session identity and tenant authorization are resolved server-side.
## Step-up
Privileged actions require fresh WebAuthn proof linked to user, session, requested action and target; short challenge TTL, one-time consumption and replay prevention. Record auth_time/assurance and require new proof after expiry. This is NOT cryptographic proof for every HTTP request; stolen cookie risk remains until revoked or expired.
## Authorization
Global users join organizations via memberships. Roles: owner/admin/member/viewer; typed permissions for organization, membership, project and billing capabilities. Use policy functions inside application use cases. Verify current membership, tenant, role and resource conditions; never trust JWT-style embedded permissions or stale cached grants. Last-owner invariants enforced transactionally.
## Recovery and revocation
Design explicit recovery threat model; no insecure email-only fallback without documented policy. Removing passkeys or changing account recovery requires recent step-up. Membership removal revokes access immediately; session revocation cannot be masked by Redis staleness.
## Negative tests
Wrong origin/RP ID, replayed challenge, unknown credential, credential belonging to another user, session fixation, expired/revoked cookie, CSRF, privilege escalation, stale membership, cross-tenant access, replayed step-up, stolen cookie without step-up.
