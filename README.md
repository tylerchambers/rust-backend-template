# rust-backend-template

Private Rust SaaS backend implementation in progress. Licensing is undecided.

## Authority

`docs/spec/` preserves the governing Notion hub, seven workstreams and four RFCs. User overrides supersede these historical snapshots: current stable Rust only; email magic links replace **all** WebAuthn, passkeys and recovery; Rust-derived OpenAPI remains authoritative. No personal/outbound email or production deployment is authorized.

See `docs/acceptance.md` for actual acceptance status. A file or scaffold is not evidence of working behavior.
